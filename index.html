How this hub works

A study tool is only worth sharing if it can be maintained, so the shape of it is written down too — and every page follows the same one.

Start at the learning path. It is the whole certificate on one page: every module says why it exists, what you must be able to do afterwards, and the facts the exams actually test — then links into the lesson and its drills. Course 1 is complete, all six modules. Course 2 Module 2 — The Network Layer — is the heaviest module in the certificate: subnetting, binary maths, ARP, routing, and most of CompTIA A+ Core 1's addressing questions.

Looking for one thing? Search the whole hub — every section, every table, every glossary definition. The index lives inside the page, so it works offline from a double-click, and a result lands on the section it matched in, not merely the page. Press / on any page to jump to the box.

What every page carries: the essentials first (objectives and the need-to-know facts, before any depth), then the teaching that explains them, then a drill after each part, then flashcards, then a quiz that explains every answer and remembers what you missed. A hover glossary on every acronym. One self-contained .html file per module — no fonts fetched, no CDN, no trackers. It works from a double-click on a plane, and from a phone.

New here? The four-step loop is on the learning path: learn, say it back, drill, prove. The drills are the proof, not the teaching.

How it was built

A study tool is only worth sharing if it can be maintained, so the process is part of the artefact.

spec first

A written page spec

Palette, type scale, section rhythm, the game API, the audio rules and the hover-glossary rule are all written down, so a page can be added later without guessing at the design.

generated

Pages are built, not hand-edited

Each module is a Python definition that emits one self-contained page. Theme, glossary and navigation are applied by the build, which is why 35 modules cannot drift apart.

gated

A verify step that can fail

Every build loads each page in a headless browser and asserts the games render, the drills accept a computed correct answer, the quiz reveals exactly one right option, every card states its question, and the contrast and tooltip rules hold. A regression fails the gate.

own wording

Definitions written for this kit

Every definition, explanation and quiz question is written here rather than copied from a course. The syllabus supplies the vocabulary; the prose is ours.

About

What this is. A personal, interactive study tool, built by working from a written spec with a local AI, to introduce, refresh, practise and drill the material in Coursera's Google IT Support Professional Certificate and CompTIA A+ Core 1 and Core 2.

What it is for. To help a learner learn the concepts introduced in Coursera's Google IT Support Professional Certificate and the CompTIA A+ Core 1 and Core 2 objectives — understand them, say them back, then prove it on the drills. It grew out of one person's own exam prep (writing the explanations was the studying) and is published for anyone working through the same material. No account, no server and no connection required: every page is one file that runs in the browser you already have.
