Charles Babbage's 1830s design for a mechanical computer with a store, a mill and punched-card input. Never finished, but it is the first description of a general-purpose programmable machine.

American Standard Code for Information Interchange: a 7-bit table of 128 codes covering English letters, digits and punctuation. A is 65, a is 97, 0 is 48 — worth memorising, because every encoding since has to stay compatible with it.

the formal name for binary: the number of distinct digits a place can hold is 2, so each place is a power of two.

Course 1 · Module 1 — Introduction to IT and Computing

Binary

counting in base 2, where each place is worth twice the one to its right and every digit is 0 or 1. A computer uses it because a transistor has two easy states: voltage, no voltage.

Course 1 · Module 1 — Introduction to IT and Computing

Binary prefixes

KiB, MiB, GiB are powers of two (1024); KB, MB, GB are powers of ten (1000). Drive makers use the second, operating systems have historically shown the first, which is why a "1 TB" drive reports about 931 GB.

Course 1 · Module 1 — Introduction to IT and Computing

one binary digit: a single 1 or 0. The smallest unit of information a computer has.

Course 1 · Module 1 — Introduction to IT and Computing

Boolean logic

the algebra of true and false, named after George Boole. Gates implement it in silicon, and it is why a search box can be described as "AND these words, NOT that one".

Course 1 · Module 1 — Introduction to IT and Computing

Byte

eight bits taken as one unit. Eight bits give 2⁸ = 256 possible values, which is enough for one character in ASCII.

Course 1 · Module 1 — Introduction to IT and Computing

the agreed mapping from a number to a character, so that a byte can mean a letter rather than just a number. Without it, the same byte is either text or arithmetic.

Course 1 · Module 1 — Introduction to IT and Computing

the number Unicode assigns to a character, written like U+0041. The code point is the identity; the encoding is how many bytes it takes to store.

how the parts are arranged and connected: processor, working memory, storage, and the buses between them.

Course 1 · Module 1 — Introduction to IT and Computing

Decimal

counting in base 10, the everyday system; each place is a power of ten, which is why humans find it natural and machines do not.

base 16, using 0–9 then A–F. One hex digit is exactly four bits, so it writes a byte in two characters instead of eight — which is why MAC addresses, IPv6 and colour codes use it.

the person who keeps other people's technology working: diagnosing faults, setting up hardware and software, explaining the fix, and writing down what was done.

four bits, or half a byte: one hex digit. Useful because every byte splits cleanly into two of them.

the red-green-blue model that encodes a colour as three numbers, one per channel. A byte per channel gives 256 × 256 × 256 colours — the same eight-bit byte doing the same job as a character.

a machine that keeps its instructions in the same memory as its data, so a program is just data that can be loaded and changed. Every computer since has been one.

hardware, operating system, software, user. Each one presents something simpler than what is underneath it, which is the whole reason the machine is comprehensible.

a microscopic switch that either passes current or blocks it, controlled by a third terminal. Two states map to 1 and 0, so enough of them can represent anything.

the standard that gives every character in every writing system a number, including emoji and scripts ASCII never covered.

Unicode Transformation Format, 8-bit: the encoding of Unicode that uses one byte for ASCII characters and up to four for everything else. Backwards-compatible with ASCII by design, which is why it won.

the small battery keeping the clock and firmware settings alive while the machine is unplugged. A dead one means the date resets and the machine stops at "press F1".

the chip that executes instructions: fetch, decode, execute, store, billions of times a second. Its speed is a clock multiplied by a factor, and its cores decide how much runs at once.

the physical connector that holds the processor: the pins, the alignment key, and the retention lever.

the wires carrying the actual values between components. Wider bus, more bits moved at once.

the memory generation in most machines built 2015-2022: 288-pin DIMMs, about 1.2 V, and a speed quoted in MT/s. DDR4 and DDR5 slots are keyed differently, so the two cannot be mixed.

Course 1 · Module 2 — Computer Components and Hardware

the current memory generation: 288-pin but keyed differently from DDR4, two 32-bit sub-channels per DIMM, and on-module power management. Faster, and it will not fit a DDR4 board.

the layer that turns a touch into coordinates. When a screen displays but ignores taps, this is usually the part that failed.

Course 1 · Module 2 — Computer Components and Hardware

the long desktop memory stick. Count the notch: it encodes the generation.

Course 1 · Module 2 — Computer Components and Hardware

Course 1 · Module 2 — Computer Components and Hardware

Course 1 · Module 2 — Computer Components and Hardware

memory that detects and corrects a single-bit error instead of crashing. Needs a supporting module, CPU and board; it is not a feature of a DDR generation.

Course 1 · Module 2 — Computer Components and Hardware

memory that keeps its contents without power and can be rewritten electrically. The ancestor of the flash chip now used for firmware, and the reason a firmware update is possible at all.

the static spark that damages components invisibly. Hence the strap, the bags, and touching grounded metal first.

the row of parallel wires that interconnects the parts of the machine; voltage on a wire is a 1, no voltage is a 0.

the standardised size and mounting of a board or case: ATX, micro-ATX, Mini-ITX. The board and the case must match.

graphics memory, tuned for enormous bandwidth rather than low latency. GDDR6 is a different design from DDR6.

Course 1 · Module 2 — Computer Components and Hardware

digital video and audio on one cable; the consumer display standard.

a backlit panel whose crystals block or pass light.

the rechargeable cell in every phone and laptop. It degrades with charge cycles and heat, and a swollen one is a safety problem rather than a performance one.

the circuit board every component connects to: socket, memory slots, expansion slots, storage and power connectors, and the firmware chip.

80 Plus

the efficiency certification for power supplies: white, bronze, silver, gold, platinum, titanium. It says nothing about build quality, which is a separate question.

Hardware

Airflow

the path air takes through a case, in at the front and out at the back or top. Positive pressure (more intake) keeps dust out; negative cools slightly better and pulls dust in.

Hardware

Backplane

the board a set of drives or cards plugs into, carrying power and signals to a controller.

Hardware

BMC / IPMI

the Baseboard Management Controller and the protocol it speaks: a small computer on the motherboard that gives remote power control and console access even when the OS is dead.

Hardware

Boot order

the sequence in which firmware tries devices. The first thing to check when a machine boots the wrong thing.

Hardware

Bootstrap

the first small program that loads the larger one. "Booting" is short for bootstrapping, which is the whole joke.

Hardware

Degraded array

a RAID set running with a failed member — still serving, no longer protected. Fix it before the next failure, not after.

Hardware

Dock

a single connector that supplies power, displays and ports to a laptop. Most "my second monitor stopped" tickets are the dock or its cable.

Hardware

ECC

Error-Correcting Code memory: detects and fixes single-bit errors in hardware. Standard on servers, rare on desktops, and the reason a server can run for years without a silent corruption.

Hardware

Fan curve

the mapping from temperature to fan speed. The difference between a quiet machine and a hot one at the same load.

Hardware

HBA

Host Bus Adapter: the card that connects a server to storage (SAS, fibre channel) rather than to a network.

Hardware

Hot swap

replacing a component while the system runs. Needs hardware and driver support, and is the reason server drive bays exist.

Hardware

Hot-pluggable

safe to connect while powered: USB, eSATA, most server drives. Not to be confused with hot-swap, which is about replacing a part in a running system.

Hardware

IOPS

Input/Output Operations Per Second: how many small random reads or writes a drive does per second. The number that matters for databases and boot times, where throughput matters for large files.

Hardware

JEDEC

the standards body for memory, and the name for the conservative default timings RAM falls back to.

Hardware

KVM switch

one keyboard, video and mouse across several machines. Named for exactly those three.

Hardware

Legacy boot / CSM

the compatibility mode that lets UEFI boot an old BIOS-style disk. Needed for some older installs, and mutually exclusive with Secure Boot.

Hardware

MBR / GPT

the two partition-table schemes. MBR is limited to four primary partitions and 2 TB; GPT is the modern one and needs UEFI.

Hardware

Memory channel

an independent path between CPU and RAM. Two sticks in the right slots give two channels and roughly double the bandwidth; two sticks in the wrong slots give one.

Hardware

Modular PSU

a supply whose cables detach, so only the ones needed are in the case. Cable management, not performance.

Hardware

NAND

the flash technology inside SSDs and USB sticks. Its cells wear out by write cycle, which is why TRIM and wear levelling exist.

Hardware

Non-volatile

keeps its contents with no power: flash, SSDs, ROM. Volatile memory (RAM) forgets, which is why a power cut loses unsaved work.

Hardware

Parity

extra data that lets a set of drives reconstruct a missing one. Costs capacity, buys the ability to survive a failure.

Hardware

PCIe lane

one serial channel of a PCIe link. An x16 slot has sixteen; a card is limited by whichever is fewer, slot lanes or card lanes.

Hardware

Platter / head / actuator

the physical parts of a hard disk: magnetic surfaces, read-write heads, and the arm that moves them. A head crash is physical contact, and terminal.

Hardware

POST code

the two-digit display on a server board showing how far POST got. The fastest diagnosis available when a machine will not boot.

Hardware

PSU rail

a separate 12 V output from the power supply with its own current limit. A 650 W unit with a weak 12 V rail cannot run a modern GPU however the total reads.

Hardware

Riser card

an adapter that turns a slot sideways or extends it, so a card fits in a low-profile or rack case.

Hardware

SAS / SATA

the two common drive interfaces. SAS is enterprise, dual-ported and expensive; SATA is consumer and fine for one drive.

Hardware

Sector

the smallest addressable unit on a disk, classically 512 bytes, now usually 4096. Misaligned partitions cost performance on 4K-native drives.

Hardware

SO-DIMM

the smaller DIMM used in laptops and mini PCs.

Hardware

Spindle / rotational speed

how fast a hard disk's platters spin: 5400, 7200, 10000, 15000 rpm. Higher is faster and louder.

Hardware

storage Latency

the delay before a read returns. Spinning disks are milliseconds, SSDs microseconds, and that gap is why an old laptop feels new with an SSD.

Hardware

Surge protector

clamps voltage spikes. Does nothing for a brownout; that is the UPS's job.

Hardware

TBW

Total Bytes Written: an SSD's rated endurance. A warranty number, not a prediction of the day it dies.

Hardware

TDP

Thermal Design Power: the heat a chip is rated to produce, in watts. A cooling budget number, not a power-consumption measurement.

Hardware

Throttling

a chip slowing itself to stay within thermal or power limits. The machine looks fine and performs at 60 %, which is why temperatures are worth watching.

Hardware

TRIM

the command that tells an SSD which blocks are no longer needed. Without it, writes get slower over time because the drive cannot pre-erase.

Hardware

Unbuffered / registered

two incompatible kinds of server and desktop memory. Registered (buffered) RAM is for servers with many DIMMs; it will not post in a desktop board.

Hardware

Volume

a formatted container with a filesystem, which may span a partition, several partitions, or several disks.

Hardware

VRM

Voltage Regulator Module: the circuitry that turns the PSU's 12 V into the sub-1 V a CPU wants, at hundreds of amps. Weak VRMs throttle a strong CPU.

Hardware

Wear levelling

the SSD firmware spreading writes across cells so one block does not die first. Invisible, and the reason endurance is quoted in total bytes written.

Hardware

XMP / EXPO

the profile that tells a motherboard to run RAM at its rated speed instead of the JEDEC default. Without it, fast RAM runs slow and nothing warns you.

Networking

Access port

a switch port belonging to exactly one VLAN, where frames arrive untagged. The normal port for a PC.

Networking

Address space

the total range an allocation covers. "We have a /24" means 256 addresses, and that number is the constraint everything else obeys.

Networking

Administrative distance

how much a router trusts one routing source over another, independent of metric. Connected beats static beats OSPF beats RIP, which is why a static route wins a tie.

Networking

AS Autonomous system

one organisation's network under a single routing policy, identified by an ASN. BGP routes between them.

Networking

Association

the step where a wireless client joins an access point and agrees on capabilities. Before authentication, which is a separate step.

Networking

Band steering

an access point nudging clients towards 5 GHz to relieve a crowded 2.4 GHz band.

Networking

Blackhole

traffic that is routed somewhere it is silently dropped, so it never arrives and no error comes back. The hardest fault to prove.

Networking

Captive portal

the web page a guest network forces you through before granting access. Authentication by browser, not by protocol.

Networking

CGNAT

carrier-grade NAT: the ISP does the translation too, so the address you see is not yours and port forwarding cannot work. Common on mobile and rural links.

Networking

Channel overlap

two access points using overlapping frequencies and interfering. Why 2.4 GHz really has only three non-overlapping channels.

Networking

Congestion

more traffic arriving than a link can forward, so packets queue and then drop. The reason QoS and buffering exist.

Networking

Converged

the state where every router's table agrees with the network. What "the network is up" actually means.

Networking

Convergence

routers agreeing on routes again after a change. Slow convergence means a window where some routers are sending traffic down a path that no longer works.

Networking

Decapsulation

the receiving half: stripping each header off as the data climbs back up.

Networking

Dirty air

an RF environment full of interference from non-Wi-Fi sources. Measured as noise floor, invisible to a link-rate display.

Networking

Distance vector

a protocol family where a router learns only what its neighbours tell it ("10.0.0.0 is 2 hops that way") and trusts them. Simple, and slow to notice a failure.

Networking

Dual stack

running IPv4 and IPv6 on the same interface at once. The normal transition state, and why a host can have two default routes.

Networking

EGP Exterior gateway protocol

a protocol that routes between autonomous systems. BGP is the only one still in real use.

Networking

Endpoint

any device at the end of a connection that sends or receives: a laptop, a phone, a server, a printer. "Endpoint security" means protecting those, not the network between them.

Networking

Flapping

an interface or route that alternates up and down. Usually a physical problem, always a log full of noise and a table that never settles.

Networking

Header

the control information at the front of a packet or frame: addresses, ports, flags, checksums.

Networking

Hidden SSID

a network that does not broadcast its name. Not a security measure: the name is still sent by every client that joins it.

Networking

Hold-down timer

a wait after a route fails before a replacement is accepted. Prevents flapping routes from thrashing the table.

Networking

Hop

one router-to-router step along a path. `tracert` counts hops, and each one is a place where delay and filtering can happen.

Networking

Hop count

the number of routers crossed. RIP's only metric, with 16 meaning "unreachable" — a hard ceiling on network size.

Networking

Hub and spoke

everything connects through one central point. Simple to secure and manage, and the centre is a single point of failure.

Networking

IGP Interior gateway protocol

a routing protocol inside one autonomous system: OSPF, EIGRP, RIP.

Networking

Inter-VLAN routing

moving traffic between VLANs, which needs a router or a layer-3 switch because VLANs are separate broadcast domains.

Networking

Link state

a protocol family where every router knows the whole topology and computes shortest paths itself (OSPF, IS-IS). Converges fast, costs memory and CPU.

Networking

Longest prefix match

the router's rule for choosing among matching routes: the most specific mask wins, always, regardless of metric or order.

Networking

Mesh

every node connected to several others so no single link is critical. The opposite of hub-and-spoke.

Networking

Metric

the number a routing protocol uses to compare two paths to the same network. Lower is usually better; hop count, bandwidth and delay are all common metrics.

Networking

MTU Maximum Transmission Unit

Maximum Transmission Unit: the largest payload one frame can carry, 1500 bytes on standard Ethernet. Get it wrong and large packets vanish silently while small ones work.

Networking

Multipoint

a link or medium shared by more than two devices, which therefore needs addressing to know who the traffic is for.

Networking

Noise floor

the background RF level a signal has to rise above. Signal minus noise is the number that actually predicts performance.

Networking

Overhead

the bytes a protocol spends on headers instead of payload. Every layer takes its cut, which is why payload is always less than the link rate.

Technical English: the cost of the mechanism itself, rather than the work. Every abstraction has some, and it is worth knowing what you are paying.

Networking

Overlapping subnets

two networks claiming the same addresses. Traffic goes to whichever route wins, which is never the one you meant.

Networking

Overlay

a logical network built on top of another, addressed separately. VPNs and VXLAN are overlays.

Networking

PAT / NAT overload

port address translation: many private hosts share one public address by giving each conversation a different source port. What home routers actually do.

Networking

Path

the sequence of hops a packet takes. IP does not promise a stable one; two packets in the same connection can take different routes.

Operating systems: where a file lives, and how a shell finds a command. Absolute paths start at the root; relative paths start where you are.

Operating systems: the list of directories the shell searches for a command. Adding a tool to PATH is how "command not found" is usually fixed.

Networking

Point-to-point

a link with exactly two ends, like a leased line or a PPP connection.

Networking

Poison reverse

advertising a failed network back as unreachable rather than staying quiet. A stronger split horizon, and part of how RIP breaks loops.

Networking

Prefix

the network part of an address, written address/length: `192.168.10.0/24`. The length is the number of bits that identify the network.

Networking

Probe request

the frame a wireless client broadcasts looking for networks. Its volume is why turning off SSID broadcast does not hide a network.

Networking

Reachability

whether a destination can be got to at all. Test it before blaming the application: ping, then traceroute, then the service.

Networking

Roaming

a wireless client moving between access points without losing its connection. Works when the APs agree, and fails visibly when they do not.

Networking

Route summarization

advertising a range of networks as one shorter-prefix route. Shrinks routing tables and hides detail that changes.

Networking

RTT

Round Trip Time: how long a packet takes to go and come back. The number `ping` reports, and the one users feel as lag.

Networking

Split horizon

the rule that a router never advertises a route back out the interface it learned it on. Stops two routers teaching each other a loop.

Networking

Static route

a route typed in by hand. Predictable and does not adapt: perfect on a stub network, a trap in a changing one.

Networking

Supernetting

combining several networks into one shorter-prefix block. The reverse of subnetting, and the point of summarization.

Networking

SVI

Switched Virtual Interface: the logical interface on a switch that gives a VLAN an IP address, so the switch can be managed or route for that VLAN.

Networking

Tie-breaker

the rule a protocol applies when two paths have equal metric. Knowing which one exists is how you predict what a router will actually do.

Networking

Topology

how the parts are connected and arranged: star, bus, mesh, hub-and-spoke. Determines what a single failure takes down.

Networking

Trailer

control fields at the *end* of a frame, such as the frame check sequence. Ethernet puts its error check there, not at the front.

Networking

Triggered update

sending a routing update immediately on a change instead of waiting for the periodic timer. Faster convergence, more traffic.

Networking

Trunk

a link that carries several VLANs at once, tagging each frame so the far end knows which VLAN it belongs to.

Networking

Tunnelling

carrying one protocol's packets inside another's. VPNs, GRE and IPv6-over-IPv4 all work this way.

Networking

Underlay

the physical network an overlay runs on. Overlay problems are usually underlay problems.

Networking

Uplink

the link from a switch or access point towards the rest of the network. Where local traffic leaves.

Networking

VLSM

Variable Length Subnet Masking: using different mask lengths in the same address space so each subnet gets only the hosts it needs.

Networking

Wildcard mask

the inverse of a subnet mask, used in ACLs and OSPF statements: a 0 bit means "must match", a 1 bit means "do not care".

Networking

WLC

Wireless LAN Controller: the device that manages many access points centrally — channels, power, SSIDs, roaming.

Operating systems

Daemon

Operating systems

Deadlock

two processes each holding something the other needs, so neither moves. The classic cause of a hung system with nothing obviously wrong.

Operating systems

Demand paging

loading memory pages only when they are touched. Makes programs start fast and explains the disk activity when too much is open.

Operating systems

Deprecation

the announcement that a feature will be removed: still works, stop building on it. A warning, not a removal.

Operating systems

Environment variable

a named value the OS gives every process: `PATH`, `TEMP`, proxy settings. The usual reason a program works in one shell and not another.

Operating systems

EULA

End User Licence Agreement: the contract accepted by installing. Rarely read, occasionally binding.

Operating systems

Exit code

the number a program returns: 0 for success, anything else for a specific failure. The reason automation branches on `$?` and not on text.

Operating systems

File system

the rules for organising data on storage: NTFS, ext4, APFS, exFAT. They differ in permissions, journaling and the maximum sizes they accept.

Operating systems

Fork

duplicating a running process so the copy can do something else. The Unix mechanism for starting work without writing an entirely new program.

Operating systems

Glob

the shell's own pattern matching, expanded before the program runs. Different from a regular expression, which the program applies itself.

Operating systems

Group Policy

the Windows mechanism for pushing settings to many machines and users from a central definition. The reason enterprise Windows looks nothing like home Windows.

Operating systems

HAL

Hardware Abstraction Layer: the layer that hides hardware differences from the rest of the OS. Windows still carries the name.

Operating systems

Handle

a reference an application holds to an OS resource: a file, a socket, a registry key. Leaked handles behave like leaked memory.

Operating systems

Hotfix

an urgent, narrow fix released outside the normal cycle. Rare and usually important.

Operating systems

Image

a byte-for-byte copy of a disk or a prepared OS install. Deployed to many machines so they start identical.

Operating systems

Kernel

the core of the operating system: schedules processes, manages memory, owns the drivers and enforces permissions. It is the only code that talks to hardware directly.

Operating systems

Legacy

still in use and no longer preferred. Not an insult; a risk designation with a migration backlog attached.

Technical English: inherited from an earlier design and still in use. A statement about history, not about quality.

License

the legal permission to use software, with its terms. The thing an audit checks, and the reason counts matter.

Local account / domain account

an account that exists only on this machine, versus one that exists in a directory and works everywhere. The difference decides who can reset its password.

Operating systems

Memory leak

a program that allocates memory and never releases it. Slow, monotonic growth that ends in a restart and no error.

Operating systems

Mount

attaching a filesystem to a place in the directory tree. In Windows letters do this job; in Unix everything mounts under one tree.

Operating systems

Multitenancy

one system serving several organisations with their data kept separate. The defining architecture of cloud services, and the source of most of their risk.

Operating systems

Mutex

the lock that stops two threads entering the same critical section. The fix for a race, with deadlock as its failure mode.

Operating systems

OOM killer

the Linux mechanism that kills a process when memory is exhausted. It picks, and it usually picks something important.

Operating systems

Page fault

a request for a page that is not in RAM, so the OS must fetch it. A few are normal; a storm of them is thrashing.

Operating systems

Pipe

sending one command's output into the next command's input. The `|` that makes small tools add up.

Operating systems

PowerShell

Microsoft's scripting shell: objects rather than text, and a real language. The standard way to administer Windows at scale.

Operating systems

Preemption

forcibly taking the CPU away from a running process. Without it, one badly written program can freeze a machine.

Operating systems

Race condition

two threads touching the same data in an order that decides the outcome. Works until it does not, and it will not be reproducible on the developer's machine.

Operating systems

Recovery partition

a hidden partition holding the tools to repair or reinstall the OS. Often the difference between a bad afternoon and a bad week.

Operating systems

Redirection

sending a command's output to a file instead of the screen (`>` overwrites, `>>` appends). The `>` one has destroyed a lot of files.

Operating systems

Registry

Windows' hierarchical settings database. Where every configuration ends up, and why "just reinstall the app" often fixes a setting.

Operating systems

Rollup

a single package containing many updates, used so a fresh install does not need hundreds of individual patches.

Operating systems

Root

the superuser account on Unix, with no permission checks. Everything is possible, including ruining everything.

Technical English: the starting point: of a filesystem, a hierarchy, a cause. "Root user" is the account at the top.

Operating systems

Seat

one licensed user or device. "How many seats" is the question that decides the invoice.

Operating systems

Service

a background program with no window, started by the OS: print spooler, DNS client, update agent. Most "the network is broken" issues are one service.

Operating systems

Service pack

a bundled set of fixes and features, largely a historical concept now that updates are continuous.

Operating systems

Shebang

the `#!` first line of a Unix script naming the interpreter that should run it. Without it the shell guesses, sometimes wrongly.

Operating systems

stdout / stderr

Subscription

Operating systems

Sudo

Operating systems

System Restore

Operating systems

Template

Tenant

one customer inside a multitenant system. Tenant isolation is the security property to ask about.

the two privilege levels. Applications run in user space and ask the kernel for anything privileged; a bug in kernel space takes the whole machine.

forcing clients off a network by spoofing management frames. A denial of service, and often the first half of an evil twin.

Security

Defence in depth

layers so one failure is not fatal. The reason a compromised endpoint does not automatically mean a compromised domain.

Security

device Jailbreak / root

removing the manufacturer's restrictions on a phone. Convenient, and it undermines the device's security model.

Security

Dictionary attack

trying a list of likely passwords. Faster than brute force, and why "Password1!" is not a strong password.

Security

DLP Data loss prevention

controls that stop sensitive data leaving: content matching on mail and web, plus endpoint rules. Catches the careless, not the determined.

Security

DNS poisoning

corrupting a name lookup so the answer points somewhere else. Either the resolver cache or the response in transit.

Security

Downgrade attack

forcing two parties to negotiate a weaker option than they support, then attacking that.

Security

DPAPI

the Windows interface applications use to encrypt secrets to the user's account. The reason a profile copy between machines breaks saved passwords.

Security

EAP

Extensible Authentication Protocol: the framework 802.1X uses to carry whatever authentication method is chosen.

Security

EDR

Endpoint Detection and Response: software that watches process behaviour and can isolate a host. The upgrade from antivirus signatures to behaviour.

Security

EFS

Encrypting File System: per-file encryption in NTFS, tied to a user certificate. Losing the certificate loses the files, which is how people learn what "key escrow" is for.

Security

Encryption

making data unreadable without a key. Reversible by design, unlike hashing.

Security

Encryption at rest

data encrypted on disk so a stolen drive is not a data breach. Protects against theft, not against a logged-in attacker.

Security

Encryption in transit

data encrypted on the wire. Protects against interception, not against either endpoint.

Security

Eradication

removing the attacker's access and the vulnerability that allowed it. Rebuild is often the only honest version.

Security

Escaping

encoding data so it cannot be interpreted as syntax in its destination. Context matters: HTML escaping does nothing for SQL.

Security

Evil twin

a rogue access point with the same SSID as a legitimate one, hoping devices join it.

Security

Exfiltration

data leaving the network without permission. Often slow and small, which is why volume alarms miss it.

Security

Exploit

the code or technique that turns a vulnerability into access.

Security

Exploit kit

a packaged set of exploits served to browsers. Mostly historical, but the delivery model reappears in every generation.

Security

False negative

a real attack that was not detected. The one that matters, and the one never counted.

Security

False positive

a detection that is not actually a problem. Its cost is the real alert it teaches people to ignore.

Security

Federation

trusting another organisation's identity provider instead of holding its users. SAML and OIDC are how it is done.

Security

FileVault

the macOS equivalent.

Security

Footprinting

the same thing, focused on the network's shape and ownership.

Security

Forensics

collecting and preserving evidence in an order that stands up: memory first, then disk, then logs.

Security

Forward secrecy

a design where one stolen long-term key does not decrypt past sessions, because each session has its own ephemeral key.

Security

Golden ticket

a forged Kerberos ticket signed with a stolen KRBTGT key, valid for the domain.

Security

Hardening

removing the default weaknesses of a system: unused services, default credentials, verbose errors, unnecessary accounts.

Security

Hashing

a one-way function producing a fixed-length digest. Used for passwords and integrity, never for encryption, because it cannot be reversed.

Security

Honeypot

a deliberately exposed decoy system. Valuable for early warning and useless unless someone reads its logs.

Security

HOTP

the counter-based variant, where each code is used once in sequence rather than timed.

Security

IAM

Identity and Access Management: the systems that create identities, assign roles and review access.

Security

IDS / IPS

Intrusion Detection System versus Intrusion Prevention System: one watches and alerts, the other sits inline and blocks. Inline blocking means a false positive becomes an outage.

Security

IKE

Internet Key Exchange: how IPsec peers agree on keys and parameters. Phase 1 and phase 2 are the two negotiations.

Security

Impersonation

pretending to be someone else, technically or socially. Phishing's payload is usually just that.

Security

Incident response

the structured handling of a security event: prepare, identify, contain, eradicate, recover, review. Skipping containment to "fix it" is how evidence is lost.

Security

Injection

the general class: input interpreted as code, whether SQL, shell, LDAP or a template. The most persistent bug category in software.

Security

Input validation

checking that data is what it should be before using it. Necessary, and never sufficient on its own.

Security

Insider threat

risk from someone with legitimate access, whether malicious or careless. Detected by behaviour and logging, not by perimeter controls.

Security

IOC

Indicator of Compromise: an artefact that suggests a specific intrusion — an address, a file hash, a registry key.

Security

IPsec

the IP-layer security suite for VPNs: authentication headers and encrypted payloads, in transport or tunnel mode.

Security

Kerberoasting

requesting service tickets and cracking them offline. Defeated by service accounts with strong, rotated passwords.

Security

Key exchange

two parties deriving a shared secret without ever sending it. Diffie-Hellman is the classic; its security rests on the discrete logarithm problem.

Security

Keylogger

records keystrokes, in software or in a physical device between keyboard and machine.

Security

Kill chain

the sequence of phases an intrusion follows: reconnaissance, weaponisation, delivery, exploitation, installation, command and control, actions.

Security

LAPS

Local Administrator Password Solution: giving every machine a different, managed local admin password. Turns a common lateral-movement path into nothing.

Security

Lateral movement

an attacker moving from one compromised host to others. The phase that credential hygiene and segmentation are for.

Security

Least functionality

turning off what is not needed. An unused service is an unpatched vulnerability waiting for a reason to exist.

Security

Malware

the umbrella: viruses, worms, trojans, ransomware, spyware.

Security

MDR

Managed Detection and Response: someone else runs the detection and response for you, usually a subscription.

Security

MFA Multi-Factor Authentication

Multi-Factor Authentication: two or more independent factors. The single most effective control against credential theft, which is why it is the first thing an attacker tries to bypass.

Security

MITM

Man-in-the-Middle: sitting between two parties, reading and possibly altering traffic. Defeated by authenticated encryption, not by encryption alone.

Security

MITRE ATT&CK

the public catalogue of those techniques, used to compare detections and describe campaigns in a shared vocabulary.

Security

NAC

Network Access Control: checking a device's posture before letting it on the network.

Security

NGFW

Next-Generation Firewall: application-aware filtering rather than port-and-address only.

Security

Nonce

a number used once. Its only job is to make a message unreplayable and a session unique.

Technical English: a value used once, to prevent replay or to make a token unique.

Security

OAuth

the delegation protocol behind "sign in with…" and API access. It authorises; it does not authenticate, which people conflate constantly.

Security

OIDC

OpenID Connect: the modern, JSON-based identity layer on top of OAuth 2.0.

Security

One-time password

a code valid once, usually time-based. Safe to intercept, useless to replay.

Security

OSINT

Open Source Intelligence: information available publicly, collected and correlated.

Security

PAM

Privileged Access Management: vaulting, rotating and recording the use of admin credentials.

Security

Parameterised query

a query where data is passed separately from the statement, so it cannot become code. The fix for injection, by construction.

Security

Pass-the-hash

authenticating with a captured password hash instead of the password. The reason credential theft is worse than password guessing.

Security

Passkey

a credential bound to a device and a site, replacing the password and resisting phishing because there is nothing to type into the wrong place.

Security

Passwordless

any scheme without a password: passkeys, hardware keys, magic links. Removes the whole class of password attacks, and adds a recovery problem.

Security

Patch management

the process of knowing what is unpatched, testing, deploying and verifying. The boring control that prevents most real breaches.

Security

Penetration test

a human attempting to exploit the system with permission and a scope. Tests the chain, not the checklist.

Security

Persistence

how malware survives a reboot: a scheduled task, a service, a startup entry. The first thing an incident responder looks for.

Security

PHI

Protected Health Information: health data tied to a person. Stricter again.

Security

Phishing

a message designed to make you click, log in or pay. The delivery mechanism for most breaches, and therefore the one control users are part of.

Security

PII

Personally Identifiable Information: data that identifies a person directly or in combination. The category with the strictest handling rules, and the one whose loss is reportable.

Security

Pretexting

inventing a plausible reason to ask. The story is the tool.

Security

Privilege escalation

going from a normal user to an administrator, by exploit or by misconfiguration. Half of all intrusions are a privilege escalation away from being serious.

Security

Privileged access

administrative rights over systems. Managed separately because it is the thing worth stealing.

Security

Proxy

an intermediary that forwards requests on your behalf. Used for filtering, logging and hiding the client.

Security

PSK Pre-shared key

a shared secret used instead of certificates. Simple for a home Wi-Fi, and impossible to rotate at scale.

Security

Quarantine

isolating a suspicious file or host without destroying it. Preserve the evidence.

Security

Rainbow table

precomputed password hashes for fast lookup. Defeated by salting.

Security

Ransomware

malware that encrypts data and sells the key back. Modern variants also exfiltrate first, so "we have backups" is only half an answer.

Security

Ransomware-as-a-service

the criminal business model where operators rent the tooling to affiliates. Explains why capability spread faster than skill.

Security

RAT

Remote Access Trojan: malware giving an attacker interactive control. The endpoint phase of most intrusions.

Security

RBAC

Role-Based Access Control: permissions attached to roles, users attached to roles. The reason an organisation can be audited at all.

Security

Reconnaissance

the attacker learning about you: open ports, job ads, DNS records, staff on LinkedIn. Half of it looks like normal traffic.

Security

Red team / blue team

attack simulation versus defence. Purple when they work together deliberately.

Security

Remote wipe

remotely erasing a device, or only the work data on it. The feature that makes BYOD defensible.

Security

Replay attack

resending a captured valid message. Defeated by nonces, timestamps or sequence numbers.

Security

Rogue access point

any unauthorised access point on the network, malicious or a user's own hotspot.

Security

Root certificate

the anchor at the top of the chain, shipped in the OS or browser. Trust is ultimately a list someone else maintains.

Security

Rootkit

malware that hides itself at a privileged level, sometimes in firmware. Removal often means rebuild, because you cannot trust the machine's own reports.

Security

Salt

random data added to a password before hashing so identical passwords produce different hashes. Stops one table cracking every account at once.

Security

SAML

Security Assertion Markup Language: the XML-based federation protocol of enterprise SSO.

Security

Sanitisation

cleaning data so it is safe to store or display. Differs from validation: one rejects, the other transforms.

Security

Secret

a credential a program needs: password, API key, token. Stored in a vault or an environment variable, never in source control.

Security

Secure enclave / TPM

a small chip that holds keys and does the protection in hardware, so malware in the main OS cannot read them.

Security

security Baseline

the agreed minimum configuration every machine must meet. Auditable; hardening without a baseline is unmeasurable.

Security

Security audit

the evidence-based review against a standard. Findings, owners and dates, or it repeats next year.

Security

Security awareness training

teaching staff what the attacks look like. Measured by click rates and reporting rates, not by completion.

Security

Self-signed certificate

one signed by itself, trusted by nobody by default. Correct for a lab, wrong for a service, and a warning everyone learns to click through.

Security

Service account

a non-human account a system uses. Often over-privileged and never expired, which makes it a favourite target.

Security

Session

the authenticated conversation between client and server, identified by a cookie or token. Session expiry exists because a stolen session is a stolen login.

Security

Shadow IT

systems and services used without IT's knowledge. Usually bought to solve a real problem, which is why banning it alone never works.

Security

Shodan

the search engine for internet-exposed devices. If a port is open to the internet, assume it is indexed.

Security

SIEM

Security Information and Event Management: the platform that collects logs and rules on them. Only as good as the logs it receives and the rules someone wrote.

Security

Smishing / vishing

the same attacks by SMS and by voice call.

Security

SOAR

Security Orchestration, Automation and Response: automating the repetitive parts of triage and containment.

Security

Spear phishing

phishing aimed at one person with real details. Harder to spot because it is correct about you.

Security

Split tunnelling

sending only some traffic through the VPN and the rest direct. Convenient, and it means some of the user's traffic is outside the corporate controls.

Security

Spoofing

forging a source address, MAC, DNS reply or caller ID. Cheap, and the reason trust should not rest on an identifier alone.

Security

Spyware

malware that watches: keystrokes, screens, browsing, credentials.

Security

SQL injection

putting SQL into an input field so the application runs it. Defeated by parameterised queries, not by filtering strings.

Security

SSO Single Sign-On

Single Sign-On: one login for many services. Convenient, and it makes one compromised identity worth more.

Security

Symmetric encryption

one shared key for both directions. Fast, and the key distribution problem is the whole difficulty.

Security

TACACS+

Cisco's alternative to RADIUS, which separates authentication, authorisation and accounting and encrypts the whole payload.

Security

Tailgating

following an authorised person through a physical door. The oldest access control bypass.

Security

Threat actor

who is attacking and with what motivation: opportunistic criminal, insider, state-backed, activist. Changes what the defences should be.

Security

Threat model

a structured answer to what you are protecting, from whom, and what would stop them. Without one, security is a shopping list.

Security

TKIP

the older encryption used by WPA. Deprecated and broken; seeing it offered is a sign of an old access point.

Security

Token

a piece of data standing in for a credential: a session token, a bearer token, a hardware key's output. Whoever holds it is treated as you.

Security

TOTP

Time-based One-Time Password: the six-digit code from an authenticator app, derived from a shared secret and the clock. Needs the clocks to agree.

Security

Trojan

malware disguised as something wanted. No self-spread; the user installs it.

Security

TTP

Tactics, Techniques and Procedures: how an actor operates, rather than what they leave behind. The durable thing to defend against.

Security

Tunnel mode / transport mode

IPsec wrapping the whole packet (site-to-site) versus only the payload (host-to-host).

Security

UTM

Unified Threat Management: one appliance doing firewall, antivirus, filtering and VPN. Convenient, and a single point of failure.

Security

Vault

the encrypted store for secrets with controlled, logged retrieval.

Security

Virus

malware that attaches to a file and spreads when the file runs. Needs a host and a user action.

Security

VPN concentrator

the device that terminates many VPN tunnels. The thing that becomes the bottleneck at 9 a.m.

Security

Vulnerability

a weakness that could be exploited. Different from a threat (who might) and a risk (what it would cost).

Security

Vulnerability scan

automated checking for known weaknesses. Noisy and shallow, and the correct starting point before a test.

Security

WAF

Web Application Firewall: inspects HTTP for application attacks. Effective against known signatures, blind to logic flaws.

Security

Whaling

phishing aimed at executives or approvers, because their authority is the prize.

Security

Windows Hello

PIN or biometric sign-in, backed by the TPM. The PIN is device-bound, which is why it is stronger than it looks.

Security

Worm

malware that spreads by itself across networks with no user action. The fastest-moving kind, and the reason segmentation exists.

Security

WPA2 / WPA3

the Wi-Fi security standards. WPA2 is the floor; WPA3 removes the offline dictionary attack on captured handshakes.

Security

WPS

Wi-Fi Protected Setup: the push-button or PIN pairing feature. The PIN variant is brute-forceable, so turn it off.

Security

XDR

Extended Detection and Response: the same idea extended across endpoint, network, email and cloud with one correlation layer.

Security

XSS

Cross-Site Scripting: injecting script into a page another user loads. The reason user input is escaped rather than trusted.

Security

Zero trust

the model where no network location is trusted by default and every request is authenticated and authorised. The opposite of "inside the firewall".

Security

Zero-day

a vulnerability with no patch and no public knowledge yet. Undefended by definition, which is why defence-in-depth matters more than patch speed alone.

Technical English

Abstract / abstraction

hiding the details behind a simpler idea, so you can think at one level. The reason a network stack is teachable at all.

Technical English

Adjacent

next to, in the sense of related but not the same. "Adjacent skill" means it transfers, not that it is identical.

Technical English

Aggregate

combined from several parts into one figure. An average is an aggregate, which is why it hides the outlier that matters.

Technical English

Alias

a second name for the same thing. In networking, an interface can hold several addresses; in a shell, a short command for a long one.

Technical English

Ambiguous

having more than one valid reading. The word to use when a requirement could be done two ways, instead of guessing.

Technical English

Applicable

applies to this case. The word auditors use to see whether a control is relevant; the word engineers use to avoid doing things that are not.

Technical English

Approximation

close enough to be useful, known not to be exact. Say which, or the number becomes a promise.

Technical English

Arbitrary

chosen without a principle behind it. A limit that is arbitrary is one someone picked; question it rather than infer meaning from it.

Technical English

Asynchronous

happening without waiting for the other side: send and continue. The opposite of synchronous, and the reason callbacks and queues exist.

Technical English

Atomic

all or nothing, with no visible in-between state. Atomic operations are the building block of anything that must not half-happen.

Technical English

Attribute

a property of something. In data, a column; in access control, a fact about a request that a rule evaluates.

Technical English

Autonomous

acting without being told, within limits. An autonomous system makes its own decisions; a human still owns the outcome.

Technical English

Backoff

waiting longer between retries. Without it, a struggling service is finished off by its own clients.

Technical English

Bespoke

built for one customer's specific need, as opposed to off-the-shelf. Costs more to build and more to maintain, and is exactly right when nothing standard fits.

Technical English

Bidirectional

in both directions. A bidirectional link can send and receive at once; a half-duplex one takes turns.

Technical English

Boolean

true or false, and the logic built on it. Every filter, rule and condition resolves to one.

Technical English

Canonical

the single agreed form of something, so comparisons have an answer. "Canonical name" is the official one; "canonical URL" is the one search engines treat as the page.

Technical English

Cascading

one failure or change triggering the next, in sequence. Cascading failure is the outage that grows while you watch.

Technical English

Caveat

the condition attached to a claim that changes when it applies. Give it with the claim, not after someone has acted on it.

Technical English

Coerce / coercion

forcing one type into another. The reason `"1" + 1` can equal `"11"` in one language and `2` in another.

Technical English

Compile

turning source code into something the machine runs. At build time, so errors appear before the user does.

Technical English

Concatenate

join end to end. Strings, files, and the reason a path is assembled rather than typed.

Technical English

Concurrency

several things making progress in the same period, not necessarily at the same instant. Distinct from parallelism, and the source of most subtle bugs.

Technical English

Concurrent

overlapping in time. Two users are concurrent; two threads are concurrent; a queue is how you handle them.

Technical English

Configure

set the parameters a system runs with. Configuration is what distinguishes two installs of the same software.

Technical English

Constraint

a limit that must be respected: time, capacity, policy, physics. Naming the binding constraint is most of a design.

Technical English

Context

the surrounding information that decides what a word or request means. "Reboot the server" needs a context to be actionable.

Technical English

Contract

an agreed interface with promises on both sides. An API contract, a data contract, a service contract: the thing that lets two teams change independently.

Technical English

Coupling

how much one component depends on another's details. Loose coupling is what lets you replace parts.

Technical English

Debounce

ignore repeated triggers until they stop, then act once. How a search box avoids a request per keystroke.

Technical English

Deterministic

same input, same output, every time. The property that makes a fault reproducible, and a test meaningful.

Technical English

Diagnostic

information that helps identify a fault: logs, codes, readings. A diagnostic is not a fix, and a fix without one is a guess.

Technical English

Discrete

separate and countable, not continuous. Packets are discrete; latency is continuous.

Technical English

Distribute

spread across locations or machines. Distributing state is easy; keeping it consistent is the whole problem.

Technical English

Downstream / upstream

the direction data or dependency flows. Upstream is the source, downstream is what depends on it — and the terms flip depending on whether you are talking about traffic or dependency.

Technical English

Durable

survives restart, crash or power loss. "Persisted" is not the same as durable; the write has to be flushed.

Technical English

Encapsulate

wrap one thing inside another. In networking, each layer wraps the one above; in software, a class hides its internals behind a method.

Technical English

Enumeration

listing every possible value or item. Useful for a dropdown, and a reconnaissance technique when the list is of accounts or ports.

Technical English

Ephemeral

lasting a short time by design: a port, a token, a container. Ephemeral is a feature, not a defect.

Technical English

Explicit vs implicit

stated versus assumed. Implicit behaviour is what makes a system surprising six months later.

Technical English

Extensible

designed so new cases can be added without changing the existing ones. The difference between a format and a standard.

Technical English

Fault tolerance

continuing to work correctly when a component fails, by design. Distinct from resilience, which is about recovering quickly.

Technical English

Flag

a value that switches a behaviour on or off, or a marker of state. A feature flag turns code off in production; a TCP flag marks a packet's purpose.

Technical English

general Index

a structure for faster lookup, or the position of an item in a list. Both meanings appear in the same afternoon.

Technical English

general Proxy

something acting on behalf of something else. Useful in every sense: network proxy, proxy data, proxy variable.

Technical English

general Session

one continuous interaction. In networking, the conversation; in support, one remote-control or chat instance.

Technical English

general Snapshot

state frozen at a moment for comparison or rollback. Not the same as a backup, in every system that offers both.

Technical English

general Tenant

one isolated customer inside a shared system.

Technical English

general Throughput

how much gets done per unit time.

Technical English

general Topology

the arrangement of the parts and their connections.

Technical English

general Wildcard

a symbol standing for any value. Powerful in search and shell, and a way to widen a permission without noticing.

Technical English

Heuristic

a rule of thumb that usually works and is not guaranteed. Most diagnosis is heuristic; say so when it is.

Technical English

Hierarchy

levels where each depends on the one below. The reason a problem can be isolated at one layer at a time.

Technical English

Implicit

understood without being stated. In configuration, the dangerous kind of assumption.

Technical English

Inherent

built in, not added. An inherent risk cannot be removed, only accepted or mitigated.

Technical English

Interoperable

different systems working together because they follow the same standard. The reason "it supports SMB3" is a better claim than "it supports file sharing".

Technical English

Iterate

repeat a process, each time improving on the last result. The normal shape of diagnosis: narrow, test, narrow again.

Technical English

Latent

present but not yet visible. A latent fault is one waiting for the right conditions, which is why testing the failure path matters.

Technical English

Lifecycle

the stages something passes through: plan, procure, deploy, operate, retire. Costs and risks differ at every stage, and retirement is the one nobody budgets for.

Technical English

Linear

proportional: twice the input, twice the work. Most systems are linear until they are not, and where they stop being linear is the useful fact.

Technical English

Manifest

a list of what something contains or needs. A build manifest, a container manifest: the declaration the system acts on.

Technical English

Mutable vs immutable

changeable versus fixed once created. Immutable infrastructure means replacing machines rather than editing them, which is what makes deployments repeatable.

Technical English

Namespace

a scope that keeps names from colliding. Two things can be called `dns` as long as they are in different namespaces.

Technical English

Normalise

reduce to a standard form so things can be compared or stored consistently. Also the data-modelling sense: one fact, one place.

Technical English

Orthogonal

independent, so changing one does not change the other. Orthogonal concerns are the ones worth separating.

Technical English

Out-of-band

through a different path than the main one. Out-of-band management is how you fix a machine whose network is down.

Technical English

Parallel

at the same instant, on separate resources. Parallelism is a hardware property; concurrency is a design property.

Technical English

Parameterise

express as a variable instead of a fixed value, so one thing serves many cases.

Technical English

Phased

done in stages, each usable. The alternative to a big-bang cutover, and usually the one that survives contact.

Technical English

Placeholder

a value that stands in for the real one. Dangerous in configuration, where a placeholder that was never replaced looks like a value.

Technical English

Policy

a decision written down in advance, so it does not have to be re-argued each time. A policy without an owner decays.

Technical English

Posture

the current state of a device's security: patched, encrypted, compliant. "Posture check" means verifying that before allowing access.

Technical English

Precision

how exactly a value is expressed. Different from accuracy: a timestamp to the nanosecond can be precisely wrong.

Technical English

Prerequisite

what must exist before the next step works. The step that gets skipped in the instructions.

Technical English

Privilege

an allowed action. Privilege is granted, capability is built in — the distinction matters when auditing access.

Technical English

Propagation

the spread of a change through a system: DNS records, routing updates, configuration pushes, cache. Delay here explains most "but I changed it" complaints.

Technical English

Proprietary

owned and controlled by one vendor, as opposed to open standard. Affects cost, integration and exit.

Technical English

Provision

supply what is needed, usually in advance: capacity, accounts, a VM. Different from configure, which sets it up.

Technical English

Pseudo-

false or resembling: pseudocode, pseudonym. A useful prefix for "close enough to reason with".

Technical English

Race

a competition whose outcome depends on timing. Only a bug when the outcome matters.

Technical English

Reconcile

bring two records or states into agreement. The normal task after any manual change.

Technical English

Redundant

duplicated so a failure does not matter. Redundancy only helps if the copies are independent.

Technical English

Refactor

restructure code without changing behaviour. Cheap now, expensive later, and the reason a codebase stays workable.

Technical English

Regression

something that used to work and now does not. A regression test exists to stop it happening twice.

Technical English

Remediate

fix the underlying problem, not the symptom. In security, remediation has a deadline; mitigation buys time.

Technical English

Replication

copying data continuously to another system. Asynchronous replication is fast and can lose recent writes; synchronous is safe and slow.

Technical English

Requirement

something that must be true for the work to be accepted. A requirement nobody can test is a wish.

Technical English

Resilience

how well a system recovers and keeps serving under failure. Different from fault tolerance: resilience assumes something will break.

Technical English

Retry

try again after a failure. Only safe when the operation is idempotent, and dangerous without backoff.

Technical English

Rollout

deploying a change to more and more of the estate, starting small. The mechanism that keeps a bad change small.

Technical English

Semantics

meaning, as opposed to syntax. Two commands can have identical syntax and different semantics, which is how a copy-paste breaks something.

Technical English

Serial

one after another. Slower by design, and sometimes the only correct way to do it.

Technical English

Specification

the written definition of what something must do. The document a bug is measured against.

Technical English

Stale

out of date but still present. Stale data, stale config, stale documentation: all more dangerous than absent.

Technical English

State

the information a system remembers between actions. Stateful systems are easier to reason about and harder to scale.

Technical English

Synchronous

the caller waits for the result. Simple to reason about, and the reason one slow dependency becomes a slow page.

Technical English

Syntax

the grammar of a language or command. A syntax error means it could not be read; a semantic error means it was read and was wrong.

Technical English

Templating

generating one thing from a pattern plus values. The basis of consistent configuration.

Technical English

Threshold

the level at which behaviour changes: an alert fires, a fan speeds up, a log rotates. A threshold nobody tuned is an alert nobody reads.
