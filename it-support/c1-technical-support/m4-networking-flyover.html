The essentials — hold these before the detail

The module at entry-certification level: what you must be able to do, and the facts the quizzes and drills on this page are testing. Read this first, every time.

You can — by the end of this module
  • say what a network is and what the internet is, in one sentence each
  • name the layers and what each one handles
  • tell a client from a server, and a LAN from a WAN
  • explain what an IP address, DNS and a router do at the level a user asks about
  • explain why the internet has the limits and privacy problems it has
Know this — the need-to-know core, 7 facts
Network
two or more devices that can exchange data. The internet is the network of networks that all speak TCP/IP.
Five layers
physical (bits on the wire), data link (frames on one network), network (packets between networks), transport (segments between programs), application (what the user asked for).
The three names users say
IP address identifies a host; DNS turns a name into an IP address; the router forwards traffic between networks.
Client and server
the client asks, the server answers. LAN is one site, WAN spans sites, and the internet is the biggest WAN there is.
Packet switching
data is split into packets that take whatever path is free and are reassembled at the destination.
The web is not the internet
the web is one application running on it, over HTTP and HTTPS on ports 80 and 443.
IoT
ordinary devices with network chips. They multiply the attack surface and are rarely patched, which is why they get their own network.
The trap: Using 'internet' and 'web' as synonyms. The web is a service that runs on the internet, the same way email does.

The internet is not the web

The distinction Course 1 makes on day one, and the one most people never unlearn.

The internetThe web
What it isThe physical and logical network: cables, routers, addresses and protocols that carry data between machines.One service that runs on top of it: documents written in HTML, fetched over HTTP, linked to each other.
AgeFrom the late 1960s (ARPANET).From 1989–91 (Tim Berners-Lee at CERN).
If it stoppedNothing else works.Email, video calls, games and file transfer would all still work.
Server
A machine that holds and serves content, running all the time.
Client
The machine asking for it: your phone, laptop or console.
ISP
Internet Service Provider — the company that already built the cabling and sells you access to it.
Protocol
An agreed set of rules for exchanging data. Without agreement, two machines connected perfectly still cannot talk.

Every request you make is a client asking a server for something. Even when it looks like a magic box doing a magic thing, it is a conversation with rules — and when it fails, the useful question is which part of the conversation stopped.

Addresses: two kinds, doing two jobs

The one idea to carry into Course 2: an IP address is end-to-end, a MAC address is hop-to-hop.

IP addressMAC address
What it isA logical address that says which network and which host on it.A physical address burned into the network card by the manufacturer.
Changes?Yes — every time you join a different network.No — generally permanent for the life of the device.
ReachEnd to end, across every network in between.One hop only. Rebuilt at every router.
Written asIPv4: four numbers 0–255. IPv6: eight hex groups.Six pairs of hex digits.
IPv4
32 bits — about 4.3 billion addresses, which ran out.
IPv6
128 bits. Eight hexadecimal groups, with runs of zeroes collapsed as ::.
NAT
Network Address Translation — one public address shared by many private hosts. The reason IPv4 lasted as long as it did.
DNS
The directory that turns a name you can remember into the address the machines need.
TCP/IP
Two protocols doing two jobs: IP delivers packets to the right machine, TCP makes sure the whole message arrives, in order. Course 2 Module 3 is the TCP half.

Why this is the exam's favourite topic: every troubleshooting question at this level starts with "is it the address or the physical link?" — and that question is the difference between the two columns above.

The four boxes in a home network

Names that get used interchangeably and should not be.

DeviceJobConfused with
ModemConverts between your ISP's medium (coax, phone line, fibre) and Ethernet in your home.Router — a modem does not route between networks.
RouterJoins two networks and decides where packets go next. In a home, it is the boundary between your private network and the internet.Switch — a router works with IP addresses and does not forward broadcasts.
SwitchConnects devices inside one network, and forwards frames only to the port that needs them, using MAC addresses.Hub — a hub repeats to every port and has not been sold for years.
Access pointBridges Wi-Fi to the wired network. The Wi-Fi in your ISP's box is an access point inside it.Router — an access point does not route.
The home "router" is all four in one box — modem, router, switch and access point. That is why the vocabulary feels abstract until you meet a business network where they are four separate devices, and why "restart the router" fixes so many things: it is really four devices restarting.

Limitations, impact, and the internet of things

The part of the module that is not technical, and the part the graded test actually asks about.

Why the internet has limits

Physics
Distance costs time. A satellite hop is ~600 ms of latency before anything else happens, which is why gaming over one is miserable.
Congestion
Shared links fill up. Everyone gets slower at once, which is why "the internet is slow" is usually a local or provider question, not a global one.
Address exhaustion
IPv4 ran out; NAT and then IPv6 are the responses.
Censorship and policy
What a network is allowed to carry is decided by governments and providers, not by the protocol.
The last mile
Rural and remote areas are expensive to reach, so they are reached last — the digital divide is a physical-infrastructure fact before it is a social one.

The internet of things

IoT is ordinary objects with a network connection: thermostats, cameras, doorbells, sensors, industrial controllers. The engineering appeal is obvious. The security problem is structural: these devices are cheap, rarely updated, often shipped with default passwords, and they sit inside the network. The 2016 Mirai botnet was built almost entirely from hacked cameras and routers, and it took down large parts of the internet for a day.

The support rule that follows: anything with a default password goes on a separate network segment, and gets its firmware updated or replaced. "It is only a doorbell" is how a doorbell becomes the way in.

Privacy, in one paragraph

Traffic is not private by default: your provider can see where you connect, the sites you visit can see your address and a great deal about your browser, and unencrypted traffic on a shared Wi-Fi network is readable by anyone on it. HTTPS and a VPN change that picture; neither makes you anonymous.
