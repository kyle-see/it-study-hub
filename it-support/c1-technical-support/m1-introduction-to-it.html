What IT is, and what this module is for

The course calls this module Introduction to IT and Computing. It is really two things: what the job is, and what the machine under the job is doing.

Information technology is using computers, networks and software to get work done — and keeping them working when they stop. That second half is the whole reason the support specialist exists.

The one sentence to own: a computer is a machine that follows instructions exactly and has no idea what they mean. Every fact in this module is a consequence of that: because it only follows instructions, it needs those instructions in a form it can represent (binary), and because it has no idea what they mean, everything that gives them meaning has to be supplied by agreement between people (encoding).

What an IT support specialist actually does

The taskWhat it looks like in one day
DiagnoseA machine will not join the network. Is it the cable, the address, the account, or the switch? Work out which question to ask first.
Fix, or routeMost tickets are solved in minutes by someone who knows the system. The rest need the right person, quickly, with enough information to act.
Set upNew starter, new machine, new phone: accounts, software, printers, permissions, and a check that it all works.
ExplainTelling a worried person what went wrong in words they can use, without making them feel stupid for asking.
RecordWriting down what happened, so the next person does not start from nothing — and so the pattern is visible when it happens for the fifth time.

The support tiers exist so that expensive expertise is not spent on password resets: tier 1 takes first contact and resolves what a script can resolve, tier 2 handles deeper diagnosis, tier 3 is the specialist engineer or the vendor.

Because every later module assumes it. Course 1 Module 2 talks about RAM capacity and drive sizes. Course 2 Module 2 asks you to convert an octet to binary in your head, twice a minute. If the eight place values are not automatic, both courses get slower at exactly the point they get interesting.

From counting boards to stored programs

The course walks this history because each step solves one problem and creates the next.

WhenMachineThe idea it added
~2500 BCEAbacusStore the number in the position of beads, not in your head. The first external memory.
1642PascalineMechanise arithmetic: gears carry the tens for you.
1837Analytical Engine (Babbage)A store, a mill and punched-card input: a general-purpose machine whose program is separate from its data. Designed, never finished — but it is the first description of a computer.
1843Lovelace's notesThe first published algorithm, and the first argument that such a machine could manipulate symbols, not just numbers.
1890Hollerith tabulatorPunched cards for the US census. Fast enough to justify a business; that business became IBM.
1945ENIACElectronic and general-purpose, around eighteen thousand vacuum tubes. Programmed by rewiring, which is why the next idea mattered.
1945Von Neumann's draftStore the program in the same memory as the data. Now a program is data: it can be loaded, copied, and changed without touching a wire.
1947TransistorReplaces the fragile, hot, power-hungry tube with a solid switch. Everything since is a story about making this smaller.
1958Integrated circuitMany transistors on one piece of silicon. The wiring stops being hand-soldered and starts being printed.
1971Intel 4004A whole processor on one chip. Computing stops being a room and becomes a component.
1981IBM PCAn open architecture other companies could copy. The reason "PC" means a category and not a brand.
1990s→The network, then the cloudThe machine stops being where the work is. Storage and processing move to somebody else's building.
Moore's law, stated honestly: in 1965 Gordon Moore observed that the number of components on a chip was doubling roughly every two years, and predicted it would continue. It is an observation and an industry roadmap, not a law of physics — and it has been slowing since the mid-2010s, which is why performance now comes from more cores and specialised chips rather than from clock speed alone.

Why a computer only needs two symbols

The machine is made of switches, so it counts in base 2 — and every other fact about bits follows from that.

A transistor is a switch, and a switch has two states

A transistor is a tiny switch controlled by a third terminal. Apply voltage and it passes current; remove it and it blocks. Two states, easy to build, easy to tell apart even when the voltage wobbles — which is exactly why computers are digital instead of analogue. One state is written 1, the other 0, and one of them is called a bit.

Bit
One binary digit — a single 1 or 0. The smallest unit of information the machine has.
Nibble
Four bits. One hexadecimal digit. Useful because every byte splits into exactly two of them.
Byte
Eight bits taken as one unit. 28 = 256 patterns, so a byte holds a value from 0 to 255.

The eight place values

Binary is a base 2 numeral system: each place is worth twice the place to its right. In a byte, read right to left:

128643216 8421
1101 1011

128 + 64 + 16 + 8 + 2 + 1 = 219. The same eight switches, read as a number.

Why 255 and not 256: there are 256 patterns, but counting starts at zero, so the highest value a byte can hold is 255. Every "the value is too large" bug in networking is this sentence.

Decimal and hexadecimal, because you need both

BaseDigitsPlace valuesWhere you meet it
Decimal (10)0–91, 10, 100, 1000Everything a human reads: 255, 192, 168.
Binary (2)0–11, 2, 4, 8, 16, 32, 64, 128Masks, prefix lengths, the actual state of the machine.
Hexadecimal (16)0–9, A–F1, 16, 256, 4096MAC addresses, IPv6, colour codes, memory addresses. Two digits = one byte.

Hex is not there to be clever. Four bits fit exactly into one hex digit, so a byte is always two characters instead of eight — 11001010 is CA. When you meet 00:1A:2B:3C:4D:5E on a MAC address, you are reading twelve hex digits, which is six bytes, which is forty-eight bits.

Counting in binary, both directions

Two methods, one for each direction. Neither needs a calculator.

Binary → decimal: add the places that hold a 1

Label the eight places, then add the ones that are switched on. That is the whole method.

BinaryPlaces that are onDecimal
0000000111
000010108 + 210
0100000164 + 165 — the capital letter A
0110100064 + 32 + 8104 — the letter h
11000000128 + 64192 — the first octet of 192.168.1.1
11111111all eight255 — the largest a byte holds

Decimal → binary: subtract the biggest place that fits

Take 200. The biggest place that fits is 128, leaving 72. Then 64 fits, leaving 8. Then 8 fits, leaving zero. So the ones are at 128, 64 and 8: 11001000.

Check your work the cheap way: if the number is odd, the last bit is 1. If it is 128 or more, the first bit is 1. Half of all mistakes are caught by those two questions alone.

Counting past 255: it is just more places

Every extra bit doubles the range: 8 bits is 0–255, 16 bits is 0–65,535, 32 bits is about 4.3 billion. That last one is why an IPv4 address was considered inexhaustible in 1981 and is now the reason IPv6 exists — and 2128 is the kind of number you stop trying to imagine.

Storage units are not the same as network units. A megabyte is eight times a mebibit, and Mb/s (megabits per second) is not MB/s (megabytes per second). A "100 Mb/s" connection downloads at about 12.5 MB/s. CompTIA A+ asks this, and so does every ISP advert that hopes you will not notice.

From bits to letters: character encoding

A byte is a number. Something has to agree what the number means, or the letter A and the number 65 are the same object.

ASCII: 128 codes, fixed forever

ASCII (American Standard Code for Information Interchange) is a 7-bit table: 128 codes covering the English alphabet, the digits and punctuation, plus a few control codes that used to move a teletype. Seven bits left one bit spare, which is why early systems had "parity" and why the first 128 codes are still identical inside every modern encoding.

CharacterDecimalBinaryWorth knowing
A6501000001The one to memorise
a9701100001Exactly 32 more than "A" — the difference between upper and lower case is one bit
04800110000Digits start here, not at zero: "0" is not the number 0
(space)3200100000A character like any other, and a common source of "invisible" bugs
The bug this causes in real life: "0" (48) and 0 (zero) are different things, and so are "1" (49) and 1. Sorting a list of numbers that arrived as text puts 10 before 2, because "1" sorts before "2". That is not a computer being stupid; it is a computer doing exactly what it was told.

Unicode and UTF-8: the same idea, for every language

ASCII's 128 codes cannot hold accented letters, Cyrillic, Arabic, Chinese or an emoji. Unicode assigns a number — a code point, written like U+0041 — to every character in every writing system. UTF-8 is how those numbers are stored: one byte for anything ASCII already covered, two to four for everything else.

Code point
The character's identity: U+0041 is "A", U+00E9 is "é", U+1F600 is 😀.
Encoding
How many bytes that identity takes on disk, and in what order the bits go.
Why UTF-8 won
An ASCII file is already valid UTF-8. Nothing old had to be rewritten, so nothing old had a reason to object.

The same byte, three different jobs

Encoding is not only about text. The same eight bits become a letter in one context, a colour channel in another, and part of an address in a third — the bits do not change, only the agreement about what they mean.

Text
01000001 is "A" under ASCII.
Colour
RGB stores one byte per channel. Red 255, green 0, blue 0 is pure red; all three at 255 is white; all three at 0 is black. 256 × 256 × 256 is about 16.7 million colours.
Picture
A pixel is one dot, and its colour is three of those bytes. A 1920×1080 image is about two million pixels — roughly six megabytes before any compression.

Logic gates: how two states become a decision

Gates are the level where electricity turns into arithmetic. There are only a handful, and each one has a truth table you can read out loud.

A logic gate is a circuit built from transistors that performs one logical operation on its inputs. Boolean logic — the algebra of true and false — is what the gate implements. Gates combine into adders, adders combine into arithmetic, and arithmetic combines into everything else.

GateRuleTruth table (A, B → out)What it is used for
NOTinverts the input0→1   1→0Negation. One input, one output.
AND1 only when every input is 100→0 01→0 10→0 11→1Two switches in series. A permission check: "logged in AND authorised".
OR1 when at least one input is 100→0 01→1 10→1 11→1Two switches in parallel. "Wired OR on battery".
XOR1 when the inputs differ00→0 01→1 10→1 11→0Addition without carrying — and the XOR-with-a-key step in encryption.
NANDAND, then inverted00→1 01→1 10→1 11→0Anything can be built from NAND alone, which is why chip designers like it.

A truth table lists every combination of inputs and the output for each. It is the complete definition of a gate — nothing is left to explain, and nothing can be ambiguous.

Why this matters to you and not just to an electrical engineer: every "and" and "or" in a config file, every firewall rule, every search query with two terms, is this algebra. A firewall rule that says "allow if port 443 and destination is the proxy" is an AND gate written in English, and the security bug is usually that someone wrote OR.

The stored-program idea, and the bottleneck it created

A stored-program computer keeps its instructions in the same memory as its data. That is what makes software possible: a program is just data that can be loaded from a disk, installed, updated, or spread by email. Von Neumann architecture is the specific layout — one memory, one control unit, instructions and data sharing the same path.

The consequence is the von Neumann bottleneck: the processor can work far faster than memory can feed it, so performance depends as much on cache and memory bandwidth as on clock speed. It is also why "just make the CPU faster" stopped working as a strategy, and why every modern CPU is a stack of caches before it is a stack of cores.

The abstraction stack, in four words: hardware, operating system, software, user. Each layer offers something simpler than the one beneath it. Module 3 is entirely about the second layer; Module 5 is entirely about the third.

Abstraction is the whole trick

The course names this as one concept. It is really the design principle that makes every other layer of a computer possible.

Abstraction means hiding detail behind a simpler surface, on purpose. You drive a car with a wheel and two pedals; you do not manage fuel mixture. The controls are the abstraction, and they are the same in a car whose engine you have never seen.

The four layers of a computer

LayerWhat it shows youWhat it hides
HardwareComponents you can touch.Electrons, voltages, timing.
Operating systemFiles, windows, a place to click.Which memory page is where, which process gets the CPU next, how a disk stores a block.
SoftwareA task: write this, send that, play this.Every system call underneath it.
UserWhat they wanted to do.Everything else.

Why the job depends on it

You are not asked to fix a transistor. You are asked to work out which layer the fault is in, because that decides who can fix it and how long it takes. A webpage that will not load could be: the browser (software), the network cable (hardware), the operating system's network settings (OS), or the user typing the wrong address (user). Four layers, four completely different investigations — and the reason "have you tried another browser" is a real diagnostic step and not a brush-off.

The support version of the abstraction rule: fix at the lowest layer that is actually broken, and change one thing at a time. Reinstalling the operating system to fix a loose cable is what happens when someone skips the layer question.

The other half of abstraction is that it leaks. An abstraction is a promise, and when the promise breaks you see underneath it: a "disk full" error in the middle of saving a document, or a printer that "just works" until the driver is the wrong version. Knowing which abstraction just leaked is most of diagnosis.
